Appearance lives in Settings → Preferences (Appearance / Personalization /
Pet / Shortcuts). Every change **applies instantly**, no restart.

## Theme system

- **Light/dark**: light, dark or follow-system, applied across all themes;
- **Theme packs**: dozens of built-in looks (from Linear's indigo to
  MiniMax's magenta-blue clash) that unify UI colors, code colors and
  background mood;
- **Accent color**: buttons, links and selection — any custom color;
- **Wallpaper**: one background image for the whole app window (conversation
  and sidebar), cropped by window ratio; wallpapers stay on each machine and
  can differ per client;
- **Editor colors**: foreground/background per light/dark mode, unoverridden
  items follow the theme preset;
- **UI font / code font / conversation width**: base UI typeface, code and
  terminal fonts, and the max column width on wide screens — all adjustable.

Themes come from [awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
(MIT) — see [License & acknowledgements](/en/reference/license).

## Desktop pet

A black-cat mascot lives on your screen: actions and speech bubbles are
event-driven (the same production pipeline), and the settings page can
simulate events for debugging.

## Shortcuts

Global and interface shortcuts are managed in Settings → Shortcuts, with
conflict detection built in.
