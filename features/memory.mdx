Agent 的「记住你」由两块组成：**人格**（它是谁、怎么说话）与
**记忆**（它记住了什么）。全部落本机文件，随时可以打开看、手动改。

## 人格

全局一份 `~/.kova/soul.md`（人格）+ `rules.md`（常驻规则），实时读盘：

- 在设置页编辑，保存即对活动会话热替换，不用重启；
- 结构化字段（称呼、语气风格）与自由文本分开管理。

## 记忆：双作用域

| 作用域 | 位置 | 用途 |
| --- | --- | --- |
| 全局 | `~/.kova/memory/` | 跨项目的长期偏好与事实 |
| 工作区 | `<cwd>/.kova/memory/` | 当前项目的具体约定（更具体，优先注入） |

- 文件粒度的 markdown，长会话同时注入两个作用域，工作区在前；
- 注入有预算：逐文件 4K / 整段 12K，超长内容中间截断——
  保证记忆再大也不会撑爆上下文。

## 检索与维护

- **`memory_search`**：Agent 可以按关键词行检索记忆，需要旧事实时主动查；
- **版本史**：每个记忆文件带 `.history/`，改动可回看；
- **回收站**：删除的记忆进 `.trash/`，不是真删；
- **追加盖时间戳**：新条目 append 时自动标记时间。

## 子代理的记忆三档

每个子代理定义声明自己的记忆档位：

| 档位 | 行为 |
| --- | --- |
| `none` | 完全无记忆——纯执行器 |
| `private` | 工作区局部的 `<cwd>/.kova/agent-memory/`，定位为中间产物 |
| `shared` | 与主记忆共享 |

五维能力声明（「未声明即不可达」）+ 记忆档位，让子代理的边界清晰可控。

<Note>
  写入有脱敏处理；身份文件（人格/记忆）刻意不放进 git 仓库——
  Agent 对仓库有写权，人格放仓库里等于可以被任何会话或 PR 改掉。
</Note>
