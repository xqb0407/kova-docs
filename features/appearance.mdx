外观与个性化集中在 设置 → 偏好(外观 / 个性化 / 桌宠 / 快捷键)，
所有改动**即时生效**，不需要重启。

## 主题系统

- **明暗模式**：浅色、深色或跟随系统，适用于所有主题；
- **主题包**：内置数十套风格主题(从 Linear 的靛蓝紫到 MiniMax 的品红蓝撞色)，
  统一界面配色、代码配色与背景氛围；
- **强调色**：按钮、链接与选中状态的主色，可自定义任意颜色；
- **壁纸**：给整个应用窗口配一张背景图(会话区与侧栏共用)，
  按窗口比例裁切构图，壁纸只存在本机，各客户端可分别设置；
- **编辑器配色**：前景/背景按明暗模式各有一套，未覆盖的项跟随主题预设；
- **UI 字体 / 代码字体 / 对话宽度**：界面基础字体、代码片段与终端字体、
  宽屏下的最大列宽，全部可调。

主题取自 [awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
(MIT)的公开网站风格逆向合集——致谢见[许可与致谢](/reference/license)。

## 桌宠

屏幕上养一只黑猫吉祥物：动作与气泡由事件驱动(走生产同款链路)，
设置页可以直接模拟事件调试。尾巴怎么摇、说什么话，都在本机。

## 快捷键

设置 → 快捷键里集中管理全局与界面快捷键，冲突检测内置。
