换工具最烦的是重新配置一遍模型。Kova 提供**一键导入**：
扫描本机其他 AI 工具的配置，把 baseUrl / API / Key / 模型列表
直接变成 Kova 的自定义服务。

## 支持导入的来源

| 来源 | 读什么 |
| --- | --- |
| **ZCode** | `provider_config.json` 的 providerRules（明文 api-key） |
| **Codex** | auth.json 与 config |
| **OpenCode** | 配置文件里的 provider 条目 |
| **CC 切换器（ccswitch）** | claude/codex/opencode 多档位配置 |

扫描是**纯本地**的：解析器只读这些工具自己的配置文件；
密文形态的凭据（如 `enc:v1:`）不读也解不开——只取明文 Key。
导入后每一项都可以编辑或弃用。

## 动态模型发现（autoDiscover）

自定义网关通常在 `/models` 端点自报模型列表。开启 autoDiscover 后：

- 请求 `/models` 与 `/v1/models` **竞速**，任一非空立即采用；
- 从网关自报字段解析能力：上下文窗口、输出上限、输入模态、思考档位；
- **合并语义是只追加**：AUTO 模型只补缺失的 id，永不覆盖你手写的模型参数；
- **缓存按 provider 落盘**（6h 新鲜期），与配置指纹绑定——换端点或换账户
  自动失效重新发现；失败冷却 10 分钟；
- 裸数组 / `{data:[...]}` / `{models:[...]}` 三种响应都认；单行脏数据只丢该行；
  图片、向量等非对话输出不注册。

## 隐私与安全

- 导入扫描只读**你自己机器上**的其他工具配置文件，不上传任何内容；
- 密钥保存走统一的加密凭据表（AES-256-GCM + 系统钥匙串）；
- autoDiscover 只向**你配置的 baseUrl** 发请求，不经过任何中间方。
