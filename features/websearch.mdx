WebSearch 让 Agent 能查网页。设计是**单一服务可配置**：你选一家搜索服务，
Agent 的所有联网搜索都走它；换一家只是改个设置，不需要动代码或重启。

预置的只有**各家官方 API**——不内置任何第三方代理或聚合端点，
那类服务走「自定义 API」由你显式填写。

## 预置服务

在 设置 → 智能体 → 网页搜索 里选择：

| 服务 | 端点 | 需要 Key |
| --- | --- | --- |
| **Tavily**（默认） | `api.tavily.com` | ✅ |
| DeepSeek Search | `api.deepseek.com` | ✅ |
| Brave Search | `api.search.brave.com` | ✅ |
| Exa | `api.exa.ai` | ✅ |
| SearXNG | 自建实例 | ❌（可选） |

默认指向 **Tavily**——官方 API、注册即用。切换服务即时生效，
切回来再切走，各家的 Key 仍然各自保留。

## 密钥安全

API Key 不进配置文件：

- Key 存**加密凭据表**（按服务命名空间），与模型 Key 同一套加密体系
  —— AES-256-GCM 落本机数据库，主密钥由系统钥匙串包裹；
- 配置 JSON 里只有服务与端点，永远没有明文 Key；
- 页面只显示「是否已配置 + 掩码」，不回显明文。

详见[安全与密钥](/features/security)。

## 自定义 API

想接聚合端点、内网网关或自建搜索，选「自定义 API」：

- **请求 URL / 方法 / Headers / Body 模板**全部可配，
  支持 `{{query}}` / `{{count}}` / `{{apiKey}}` 占位符；
- 响应按你声明的字段路径提取（`resultsPath` / `titlePath` / `urlPath` …），
  解析不出结构化结果时自动退回通用解析（JSON 数组 / markdown 分块）；
- GET 请求可以把 Key 放在 query 里——错误回显时会自动脱敏。

### JSON / cURL 快速配置

嫌表单繁琐?自定义服务支持两种整段配置方式:

- **JSON 编辑**:一键导出当前定义(带 `$schema` 校验),改完「应用」写回表单;
- **粘贴 cURL 导入**:从终端复制 curl 命令,方法 / URL / Headers / Body
  自动填好——导入后把查询词的值替换为 `{{query}}` 即可。

`resultsPath` 还支持网关把结果数组**序列化成字符串**塞在字段里的形态
(如 `{"result":"[{…}]"}`)——应用会自动二次解析。

## 测试按钮的安全边界

设置页的「测试」用**草稿配置**实时搜一次，不落库。安全规则：

- 已保存的 Key 只会发往**同一服务的同一端点**或该服务的**官方端点**；
- 改了端点的草稿一律不带 Key——被攻破的渲染进程无法借测试按钮
  把密钥发往任意第三方。

## 总开关

关闭网页搜索后，WebSearch 不再进入活动会话的工具表——
主代理、子代理、计划模式、`run_code` 同步失去该工具。
重新打开立即恢复，不需要重启应用。
