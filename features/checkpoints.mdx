Agent 改了文件之后，你不必信任它——每个会话的每次调用与文件改动都记成
**检查点**，随时回到某一步重来。

## 工作方式

- **影子 git-dir**：检查点不写进你的 `.git`，而是落在独立的影子目录
  （目录名由内容哈希派生，LRU 上限 20，同树复用）——你的仓库历史
  干干净净，Agent 的试错不留下痕迹；
- **反向 patch 存档**：每次改动存的是反向 patch，回滚 = `apply -R`，
  精确回到改动之前；
- **逐文件粒度**：可以只回滚某一个文件，而不是整轮推倒。

## 交互

- 会话里每个检查点可见，点击查看该步改了什么；
- 从检查点恢复：文件回到当时状态，Agent 从那一步继续；
- `git-changed` 事件实时同步——界面上的改动状态与仓库真实状态一致。

## 与检查点审阅的关系

配合[统一收件箱](/features/inbox)，一轮改动完成可以进入「审阅」——
先看 diff 再决定接受或回滚（v1.1 路线）。现在，检查点已经覆盖
「随时回退」的核心需求。
