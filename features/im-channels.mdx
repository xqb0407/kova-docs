扣瓦可以把助手接到你已经在用的聊天工具上：**微信、飞书、钉钉、企业微信**的机器人
双向接入。消息从聊天工具进来，绑定到一个桌面会话，agent 处理完把回复经通道发回去——
所有 AI 处理、工具执行、会话存储都还在你自己桌面的 sidecar 里，
聊天工具只是一个入口。

管理入口在**侧边栏「远程」→「接入 IM」**页签：创建 Bot、扫码/填凭据绑定、
选择会话、设工作目录、删除。

## 绑定模型

一个聊天**持久映射到一个桌面会话**：

- 首条消息自动新建会话（工作目录取 Bot 配置），同时下发一次引导消息，
  告知可直接对话，并列出 `/new` 开新对话、`/clear` 压缩上下文、`/stop` 停止任务；
- 此后该聊天每条消息路由到同一会话（连续对话），app 重启绑定保持；
- Bot 详情页可把 Bot **钉到指定会话**（单会话模式）。

## 访问控制（owner 门）

每通道首个私聊者自动成为 owner，陌生人消息一律拒绝并回固定提示——不会凭空建会话。
详情页「访问控制」可查看 owner（脱敏）并重置，重置后下一条私聊重新成为 owner。

## 回复颗粒度

详情页下拉，四档：

| 档位 | 行为 |
| --- | --- |
| 标准回复 | 助手正文逐条即时回传 |
| 完整回复 | 正文 + 该轮工具调用摘要（工具名 + 参数提示 + 失败标记） |
| 摘要回复 | 整轮压成一行速览（首行 + 工具调用次数） |
| 实时进度 | 额外推送每回合一条思考片段与工具执行进度，处理期间维持"对方正在输入" |

## 思考深度

侧车默认不产生思考事件。通道配置可单独设思考深度（关闭/低/中/高），
新建绑定时对该会话下发，改配置时应用到该通道全部已绑定会话。
选「实时进度」而思考仍关闭时，前端会自动把思考深度切到「低」——
否则没有思考内容可推。档位越高回复越慢、费用越高。

## 通道管理闭环

详情页包含：启用/停用开关（只停长轮询，不解绑）、绑定/解绑、选择会话、
回复颗粒度、工作目录、访问控制（owner 展示/重置 + **发送测试消息**）、删除 Bot。
测试消息复用该通道最近一次入站目标；通道停用时直接拒绝。

## 已知边界

- 当前**仅私聊 / 单聊**，无群聊能力；
- 非文本消息（图片 / 语音 / 文件）首发降级忽略；
- 审批与提问交互在 IM 侧不展示卡片：桌面端照常弹卡，IM 回复提示到桌面端确认；
- 凭据先校验后加密落库，与[模型 API Key](/features/security) 同一套加密存储。
