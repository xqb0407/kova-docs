资料库是 Agent 的本地素材库：把文档、笔记与参考资料放进一个统一目录，
Agent 经 **@ 提及**和**知识检索**随时取用。核心原则一句话：
**文件是唯一真值**——标题与标签只是可随时重建的元数据层。

## 形态

- 库根可配置（默认在应用数据目录内）；支持多个知识库维度
  （全局库 + 按工作区划分）；
- 内容 = 你导入的文件 + 应用内「存为笔记」写出的 Markdown；
- 路径被严格约束在库根之内（symlink 逃逸防护）。

## 日常操作

| 操作 | 说明 |
| --- | --- |
| 导入文件 | 拖入或选择文件进入库 |
| 存为笔记 | 把一段正文写成库内 Markdown；重名按 Finder 习惯自动加序号 |
| 标题与标签 | 元数据与文件分离管理；@ 选择器**立刻**可搜到新改的标题 |
| 移动/删除 | 移动保留标签；应用内删除会清理元数据 |
| 引用检查 | 检查库内引用关系，改名/移动后不会留下死链 |
| 文件监控 | 库目录有 watcher——文件被外部改动或恢复后，标签自动回来 |

## Agent 怎么用

- **@ 提及**：在输入框 `@` 一个条目，内容进入上下文；
- **知识检索**：Agent 有专门的检索工具，按最近使用 ∪ 最近修改排序，
  标题/标签/文件名/路径加权打分；
- 排序口径是**渲染层与 sidecar 共用的同一份纯函数**——
  界面看到的顺序与 Agent 拿到的顺序一致。

## 与备份的关系

资料库在备份的「按开关」清单里——勾上它，库内容随 `.piabk` 一起走。
详见[备份与恢复](/features/backup)。
